# Data (not included)

The ReelIndie database is course material for MIS 304 at the University of Arizona, so it is not published here.

To run the scripts, export these tables from the ReelIndie Access database as CSV files into this folder:
`rental.csv`, `payment.csv`, `film.csv`, `film_category.csv`, `category.csv`, `customer.csv`, `address.csv`, `city.csv`, `country.csv`
